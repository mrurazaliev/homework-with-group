# 🎓 Online Learning Platform

## 📌 About the Project

Online Learning Platform is a responsive educational website built using HTML5 and Tailwind CSS. The website allows users to explore online courses, browse categories, connect with mentors, and read educational blog articles.

This project was developed as a front-end practice project focusing on responsive design and modern UI development.

---

## 🚀 Features

- Responsive Navigation Bar
- Hero Section with Search Bar
- Trending Courses Section
- Course Categories
- Mentor Promotion Section
- Student Testimonials
- Latest Blog Section
- Responsive Footer
- Mobile-Friendly Layout

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Flexbox
- CSS Grid
- Responsive Web Design (RWD)

## 📱 Responsive Design

The website is fully responsive and works on:

- Mobile Devices
- Tablets
- Laptops
- Desktop Computers

Responsive layouts were created using Tailwind CSS utility classes.
